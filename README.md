# Diplom-_-2

Отчет о выполнении задания «Автотесты для API Stellar Burgers»
1. Цель работы
Разработать набор автотестов для тестирования API учебного сервиса Stellar Burgers. Проверить эндпоинты создания пользователя, логина пользователя и создания заказа.

2. Инструменты и технологии
Язык: Java

Сборщик: Maven

Тестовый фреймворк: JUnit 4

Библиотека для API-тестов: REST Assured

Фреймворк для отчетов: Allure

3. Что было сделано
3.1. Настройка проекта
Создан отдельный репозиторий для API-тестов.

Создан Maven-проект с подключенными зависимостями:

JUnit 4

REST Assured

Allure

Настроен плагин Allure для генерации отчетов.

3.2. Написание тестов
Эндпоинт: Создание пользователя
Тест-кейс	Результат
Создать уникального пользователя	✅ Пройден
Создать пользователя, который уже зарегистрирован	✅ Пройден
Создать пользователя, не заполнив одно из обязательных полей (например, email)	✅ Пройден
Эндпоинт: Логин пользователя
Тест-кейс	Результат
Вход под существующим пользователем	✅ Пройден
Вход с неверным логином и паролем	✅ Пройден
Эндпоинт: Создание заказа
Тест-кейс	Результат
Создание заказа с авторизацией	✅ Пройден
Создание заказа без авторизации	✅ Пройден
Создание заказа с ингредиентами	✅ Пройден
Создание заказа без ингредиентов	✅ Пройден
Создание заказа с неверным хешем ингредиентов	✅ Пройден
4. Результаты тестирования
Все запланированные тесты выполнены успешно.

Код тестов размещен в репозитории.

Сгенерирован отчет Allure с детализацией по каждому тесту.
